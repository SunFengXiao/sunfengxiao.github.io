## 页面说明

### 首页 (index.html / index-en.html)
- 展示个人照片、基本信息和学术简介
- 展示研究方向、工作经历和教育背景
- 提供中文与英文对应页面

### 研究领域 (research.html / research-en.html)
- 详细介绍研究方向和学术成果
- 包括量子光学、量子信息、非高斯量子态等内容
- 展示代表性研究项目和理论成果

### 论文发表 (publications.html / publications-en.html)
- 按年份组织已发表的 SCI 论文列表
- 每篇论文包含标题、作者、期刊、链接等信息
- 展示手动维护的论文总数、引用次数和 h-index 等统计

### 联系我们 (contact.html / contact-en.html)
- 提供办公地点和电子邮箱
- 显示学术链接（Google Scholar、Web of Science、ResearchGate、ORCID）
- 包含学生招募信息

### 样式表 (style.css)
- 统一的颜色主题和排版设置
- 响应式布局，适配各种屏幕尺寸
- 卡片式设计、阴影效果等现代 UI 元素

### 导航脚本 (navbar.js / navbar-en.js)
- 分别维护中文与英文页面的导航文字和地址
- 页面切换时的活动状态指示
